# 01-a — 기능 요구사항 (사용자 관점)

> **사용자 관점** 기능 요구사항(FR-NN): 사용자가 무엇을 할 수 있는가.
> 체크박스로 완료 여부를 표시한다. 구현 관점은 `01-requirements.md`(REQ-N-M) 참조.
> 작성·갱신 규칙: `.claude/rules/requirements.md`.

## 우선순위 / 미완성 표
_최종 업데이트: YYYY-MM-DD_

| FR | 제목 | 우선순위 | 완료 | 관련 REQ |
|----|------|----------|------|----------|
| FR-01 | [제목] | P1 | ❌ | REQ-1-1 |
| FR-02 | [제목] | P2 | ❌ | REQ-1-2 |

> 우선순위: P0(필수·블로커) / P1(중요) / P2(있으면 좋음) / P3(향후).
